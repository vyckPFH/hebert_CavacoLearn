# UC01 — Realizar Cadastro

#### Requisito: RF001
#### Ator(es): Aluno, Administrador

#### Pré-condições
O usuário não possui uma conta cadastrada.
O sistema está disponível para receber a solicitação.

#### Fluxo principal
O usuário acessa a tela de login.
Seleciona a opção de cadastro.
O sistema apresenta o formulário de cadastro.
O usuário informa os dados solicitados.
O usuário confirma o cadastro.
O sistema valida os dados informados.
O sistema verifica se o nome de usuário está disponível.
O sistema registra o novo usuário no banco de dados.
O sistema confirma a realização do cadastro e direciona o usuário de volta à tela de login.

#### Fluxos alternativos/exceções
A1. Dados obrigatórios não preenchidos: o sistema solicita o preenchimento dos campos.
A2. Dados inválidos: o sistema informa os dados que precisam ser corrigidos.
A3. Nome de usuário já existente: o sistema impede o cadastro e solicita outro nome.
A4. Falha na comunicação com a API: o sistema informa que não foi possível concluir o cadastro.

O cadastro deve respeitar a existência de um único perfil por usuário e a obrigatoriedade de nomes de usuário únicos.
