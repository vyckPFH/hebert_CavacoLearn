# UC02 — Realizar Login

#### Requisito: RF002
#### Ator(es): Aluno, Administrador

#### Pré-condições
O usuário possui uma conta cadastrada.
O sistema está disponível.

#### Fluxo principal
O usuário acessa a tela de login.
Informa suas credenciais.
Solicita o acesso.
O sistema envia as informações para a API.
O sistema valida as credenciais.
O sistema autentica o usuário.
O sistema identifica o perfil do usuário.
O sistema direciona o usuário para a tela home/inicial.

#### Fluxos alternativos/exceções
A1. Credenciais inválidas: o sistema informa que os dados de acesso estão incorretos.
A2. Campos obrigatórios não preenchidos: o sistema solicita o preenchimento.
A3. Falha na comunicação: o sistema informa que não foi possível realizar a autenticação.
A4. Sessão não estabelecida: o usuário permanece na tela de login.

A autenticação é obrigatória para acesso aos conteúdos do aplicativo. O artigo também prevê a comunicação entre usuário e servidor por meio de API REST.
