# UC03 — Realizar Logout

#### Requisito: RF003
#### Ator(es): Aluno, Administrador

#### Pré-condições
O usuário está autenticado.

#### Fluxo principal
O usuário seleciona a opção de logout.
O sistema encerra a sessão autenticada.
O sistema remove as informações de sessão necessárias.
O sistema direciona o usuário para a tela de login.

#### Fluxos alternativos/exceções
A1. Falha no encerramento da sessão: o sistema informa o problema ao usuário.
