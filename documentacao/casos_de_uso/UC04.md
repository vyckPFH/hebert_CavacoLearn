# UC04 — Visualizar Perfil

#### Requisito: RF004
#### Ator: Aluno

#### Pré-condições
O aluno está autenticado.

#### Fluxo principal
O aluno acessa a tela de perfil.
O sistema consulta os dados associados ao usuário.
O sistema recupera as informações do perfil.
O sistema apresenta os dados pessoais.
O sistema apresenta as informações de progresso e pontuação disponíveis.

#### Fluxos alternativos/exceções
A1. Falha na consulta: o sistema informa que não foi possível carregar o perfil.
A2. Sessão inválida: o sistema direciona o usuário para a tela de login.
A3. Falha de comunicação: o sistema informa que os dados não puderam ser obtidos.

O perfil previsto deverá apresentar dados pessoais, progresso, pontuação e quantidade de níveis e missões concluídas.
