# UC05 — Editar Perfil

#### Requisito: RF005
#### Ator: Aluno, Administrador

#### Pré-condições
O usuário está autenticado.
O perfil do usuário existe.

#### Fluxo principal
O usuário acessa seu perfil.
Seleciona a opção de edição.
O sistema apresenta os dados atuais.
O usuário altera as informações desejadas.
O usuário confirma as alterações.
O sistema valida os dados.
O sistema atualiza o perfil.
O sistema confirma a atualização.

#### Fluxos alternativos/exceções
A1. Dados inválidos: o sistema solicita a correção.
A2. Nome de usuário já utilizado: o sistema impede a alteração.
A3. Falha na comunicação: o sistema informa que não foi possível atualizar o perfil.
A4. Operação cancelada: o sistema mantém os dados anteriores.
