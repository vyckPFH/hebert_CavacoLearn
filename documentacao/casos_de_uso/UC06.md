# UC06 — Excluir Conta

#### Requisito: RF006
#### Ator: Aluno, Administrador

#### Pré-condições
O aluno está autenticado.

#### Fluxo principal
O aluno acessa as configurações do perfil.
Seleciona a opção de exclusão da conta.
O sistema solicita confirmação.
O aluno confirma a exclusão.
O sistema remove o cadastro do usuário.
O sistema remove os registros associados à conta.
O sistema encerra a sessão.
O sistema retorna à tela de login.

#### Fluxos alternativos/exceções
A1. Exclusão cancelada: o sistema mantém a conta e os registros.
A2. Falha na exclusão: o sistema informa o erro e mantém os dados.
A3. Falha na comunicação com o servidor: o sistema informa que a exclusão não foi concluída.
