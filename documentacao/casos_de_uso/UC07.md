# UC07 — Gerenciar Níveis

#### Requisito: RF007
#### Ator: Administrador

#### Pré-condições
O administrador está autenticado.

#### Fluxo principal
O administrador acessa o gerenciamento de níveis.
O sistema consulta os níveis cadastrados.
O sistema apresenta a listagem.
O administrador seleciona uma operação: cadastrar, visualizar, editar ou excluir.
Caso seja cadastro, o administrador informa os dados do novo nível.
Caso seja edição, o administrador altera os dados do nível selecionado.
Caso seja exclusão, o administrador seleciona o nível e confirma a operação.
O sistema valida a operação.
O sistema registra a alteração no banco de dados.
O sistema atualiza a listagem.

#### Fluxos alternativos/exceções
A1. Dados inválidos: o sistema solicita correção.
A2. Nível não encontrado: o sistema informa que o registro não existe.
A3. Exclusão com conteúdos associados: o sistema deve verificar as dependências antes de realizar a exclusão.
A4. Operação cancelada: nenhuma alteração é realizada.
A5. Falha na comunicação: o sistema informa que a operação não pôde ser concluída.

O gerenciamento administrativo deve ser restrito ao administrador. Além disso, a estrutura do curso deve manter pelo menos um tópico ou exercício associado ao nível.
