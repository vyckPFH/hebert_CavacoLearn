# UC08 — Gerenciar Tópicos

#### Requisito: RF008
#### Ator: Administrador

#### Pré-condições
O administrador está autenticado.
Existe um nível ao qual o tópico possa ser associado.

#### Fluxo principal
O administrador acessa o gerenciamento de tópicos.
O sistema apresenta os tópicos cadastrados.
O administrador seleciona uma operação: cadastrar, visualizar, editar ou excluir.
No cadastro, informa os dados do tópico e seu nível.
Na edição, altera os dados ou o conteúdo.
Na exclusão, seleciona o tópico e confirma a operação.
O sistema valida a operação.
O sistema persiste a alteração.
O sistema atualiza a listagem.

#### Fluxos alternativos/exceções
A1. Nível inexistente: o tópico não pode ser associado.
A2. Conteúdo não informado: o sistema rejeita o cadastro ou alteração.
A3. Tópico não encontrado: o sistema informa o erro.
A4. Tópico possui exercícios associados: o sistema verifica as dependências antes da exclusão.
A5. Operação cancelada: nenhuma alteração é realizada.
A6. Falha na comunicação: o sistema informa o erro.

Todo tópico deve possuir conteúdo associado, e as alterações realizadas pelo administrador devem refletir na estrutura apresentada aos alunos.
