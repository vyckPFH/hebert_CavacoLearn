# UC09 — Gerenciar Exercícios

#### Requisito: RF009
#### Ator: Administrador

#### Pré-condições
O administrador está autenticado.
Existe uma estrutura de curso à qual o exercício possa ser associado.

#### Fluxo principal
O administrador acessa o gerenciamento de exercícios.
O sistema apresenta os exercícios cadastrados.
O administrador seleciona uma operação: cadastrar, visualizar, editar ou excluir.
No cadastro, informa os dados e associa o exercício à estrutura correspondente.
Na edição, altera os dados ou conteúdo.
Na exclusão, seleciona o exercício e confirma.
O sistema valida a operação.
O sistema persiste a alteração.
O sistema atualiza a listagem.

#### Fluxos alternativos/exceções
A1. Associação inválida: o sistema impede o cadastro.
A2. Conteúdo não informado: o sistema rejeita o cadastro ou alteração.
A3. Exercício não encontrado: o sistema informa o erro.
A4. Exercício possui registros associados: o sistema verifica as dependências antes da exclusão.
A5. Operação cancelada: nenhuma alteração é realizada.
A6. Falha na comunicação: o sistema informa o erro.
