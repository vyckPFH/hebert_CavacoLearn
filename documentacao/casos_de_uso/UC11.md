# UC11 — Estudar Tópico

#### Requisito: RF011
#### Ator: Aluno

#### Pré-condições
O aluno está autenticado.
O tópico está disponível.
O tópico possui conteúdo associado.

#### Fluxo principal
O aluno acessa os níveis.
Seleciona um nível.
O sistema apresenta os tópicos na ordem definida.
O aluno seleciona um tópico.
O sistema solicita o conteúdo por meio da API.
O sistema recebe os blocos de conteúdo.
O aplicativo identifica o tipo de cada bloco.
O aplicativo renderiza os componentes na ordem cadastrada.
O aluno estuda o conteúdo.

#### Fluxos alternativos/exceções
A1. Sem conexão com a internet: o sistema verifica se o tópico foi previamente baixado e utiliza o conteúdo armazenado no dispositivo, caso esteja disponível.
A2. Conteúdo inexistente: o sistema informa que o conteúdo não está disponível.
A3. Falha na API: o sistema informa que não foi possível carregar o conteúdo.
A4. Tipo de conteúdo não suportado: o sistema não consegue renderizar o componente correspondente e informa a indisponibilidade.

O funcionamento considera a API REST, a renderização dinâmica dos blocos e o acesso offline aos conteúdos previamente baixados.
