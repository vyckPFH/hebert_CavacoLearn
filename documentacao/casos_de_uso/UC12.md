# UC12 — Realizar Exercício

#### Requisito: RF012
#### Ator: Aluno

#### Pré-condições
O aluno está autenticado.
O exercício está disponível.
O exercício possui conteúdo associado.

#### Fluxo principal
O aluno acessa um nível.
Seleciona um exercício.
O sistema solicita o conteúdo à API.
O sistema recebe os dados do exercício.
O aplicativo renderiza o conteúdo.
O aluno realiza a atividade proposta.
O aluno finaliza o exercício.

#### Fluxos alternativos/exceções
A1. Exercício baixado: o sistema pode utilizar o conteúdo armazenado localmente.
A2. Sem conexão e exercício não baixado: o sistema informa que o conteúdo não está disponível offline.
A3. Conteúdo inexistente: o sistema informa o problema.
A4. Falha na comunicação: o sistema informa que não foi possível carregar o exercício.
