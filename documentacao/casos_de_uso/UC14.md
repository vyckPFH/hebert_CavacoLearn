# UC14 — Concluir Exercício

#### Requisito: RF014
#### Ator: Aluno

#### Pré-condições
O aluno está autenticado.
O exercício está disponível.

#### Fluxo principal
O aluno acessa o exercício.
Realiza a atividade.
Seleciona a opção de conclusão.
O sistema registra a conclusão para aquele usuário.
O sistema atualiza o progresso.
O sistema verifica as condições relacionadas às missões.

#### Fluxos alternativos/exceções
A1. Exercício já concluído: o sistema mantém o registro existente.
A2. Falha no registro: o sistema informa o problema.
A3. Falha na atualização: o sistema informa o erro.
