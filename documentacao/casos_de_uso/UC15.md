# UC15 — Visualizar Missões

#### Requisito: RF015
#### Ator: Aluno

#### Pré-condições
O aluno está autenticado.

#### Fluxo principal
O aluno acessa a tela de missões.
O sistema consulta as missões relacionadas ao usuário.
O sistema verifica o estado de cada missão.
O sistema apresenta as missões disponíveis.
O aluno visualiza as atividades e seu estado de conclusão.

#### Fluxos alternativos/exceções
A1. Nenhuma missão disponível: o sistema informa que não existem missões disponíveis.
A2. Falha na consulta: o sistema informa o erro.

A conclusão das missões deve ser identificada a partir das ações realizadas pelo usuário.
