# UC16 — Resgatar Pontos

#### Requisito: RF016
#### Ator: Aluno

#### Pré-condições
O aluno está autenticado.
Existe uma missão concluída.
A recompensa ainda não foi resgatada.

#### Fluxo principal
O aluno acessa a tela de missões.
O sistema identifica uma missão concluída.
O sistema disponibiliza a opção de receber a recompensa.
O aluno seleciona a opção.
O sistema verifica se a missão foi concluída.
O sistema verifica se a recompensa ainda não foi resgatada.
O sistema registra o resgate.
O sistema adiciona os pontos à pontuação do usuário.
O sistema atualiza a pontuação apresentada no perfil.

#### Fluxos alternativos/exceções
A1. Missão não concluída: o sistema não permite o resgate.
A2. Recompensa já resgatada: o sistema impede um novo resgate.
A3. Falha no processamento: o sistema não altera a pontuação e informa o erro.

As regras RN010–RN013 determinam que os pontos dependem do resgate de uma missão concluída e que cada recompensa pode ser resgatada uma única vez por usuário.
