# UC17 — Visualizar Músicas

#### Requisito: RF017
#### Ator: Aluno

#### Pré-condições
O aluno está autenticado.

#### Fluxo principal
O aluno acessa a tela de músicas.
O sistema consulta as músicas disponíveis.
O sistema verifica as músicas desbloqueadas para aquele usuário.
O sistema apresenta as músicas que podem ser acessadas.
O aluno seleciona uma música.

#### Fluxos alternativos/exceções
A1. Música bloqueada: o sistema impede o acesso à música.
A2. Falha na consulta: o sistema informa o erro.
A3. Sem conexão: o sistema verifica os conteúdos de música disponíveis localmente.

O acesso às músicas é individual e condicionado ao desbloqueio definido pelo sistema.
