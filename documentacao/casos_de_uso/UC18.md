# UC18 — Estudar Música

#### Requisito: RF018
#### Ator: Aluno

#### Pré-condições
O aluno está autenticado.
A música está desbloqueada.
A música possui conteúdo associado.

#### Fluxo principal
O aluno seleciona uma música desbloqueada.
O sistema verifica a permissão de acesso.
O sistema recupera o conteúdo.
O aplicativo renderiza os blocos na ordem definida.
O aluno acessa as instruções e recursos disponíveis.
O aluno estuda a música.

#### Fluxos alternativos/exceções
A1. Música bloqueada: o sistema impede o acesso.
A2. Sem conexão: o sistema verifica se existe uma versão previamente baixada.
A3. Música não baixada: o sistema informa que não é possível acessá-la offline.
A4. Conteúdo indisponível: o sistema informa o problema.
