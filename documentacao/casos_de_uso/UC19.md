# UC19 — Visualizar Progresso

#### Requisito: RF019
#### Ator: Aluno

#### Pré-condições
O aluno está autenticado.

#### Fluxo principal
O aluno acessa a área de progresso.
O sistema consulta as conclusões registradas.
O sistema identifica os tópicos e exercícios concluídos pelo usuário.
O sistema obtém o progresso correspondente.
O sistema apresenta a evolução do aluno.

#### Fluxos alternativos/exceções
A1. Nenhuma atividade concluída: o sistema apresenta o progresso inicial.
A2. Falha na consulta: o sistema informa que o progresso não pôde ser carregado.
A3. Falha de comunicação: o sistema informa o erro.

O progresso deve ser individual e atualizado a partir das conclusões registradas para o usuário.
