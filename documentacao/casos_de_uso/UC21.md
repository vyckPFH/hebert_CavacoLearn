# UC21 — Definir Ordem dos Itens

#### Requisito: RF021
#### Ator: Administrador

#### Pré-condições
O administrador está autenticado.
Existem tópicos e/ou exercícios cadastrados.

#### Fluxo principal
O administrador acessa um nível.
O sistema apresenta os tópicos e exercícios associados.
O administrador altera a ordem dos itens.
O administrador confirma a nova sequência.
O sistema valida a alteração.
O sistema armazena a nova ordem.
A estrutura atualizada passa a ser utilizada pelo aplicativo.

#### Fluxos alternativos/exceções
A1. Ordem inválida: o sistema impede o salvamento.
A2. Operação cancelada: a ordem anterior é mantida.
A3. Falha na atualização: o sistema informa o erro.
A4. Estrutura inconsistente: o sistema impede a alteração caso ela viole as regras estruturais do curso.

A ordem dos tópicos e exercícios deve seguir a sequência definida pelo administrador e a progressão do curso deve ser pedagógica.
