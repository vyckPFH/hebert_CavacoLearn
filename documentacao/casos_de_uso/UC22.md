# UC22 — Visualizar Usuários

#### Requisito: RF022
#### Ator: Administrador

#### Pré-condições
O administrador está autenticado.

#### Fluxo principal
O administrador acessa a área de usuários.
O sistema solicita os usuários cadastrados.
O sistema consulta os dados armazenados.
O sistema apresenta a lista de usuários.
O administrador visualiza os usuários cadastrados.

#### Fluxos alternativos/exceções
A1. Nenhum usuário cadastrado: o sistema informa que não existem usuários.
A2. Falha na consulta: o sistema informa que os usuários não puderam ser carregados.
A3. Falha na comunicação com a API: o sistema informa o erro.
